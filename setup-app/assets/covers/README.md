# Cover presets

These six photographs are distributed under the [Unsplash License](https://unsplash.com/license) for use as vault covers. Original photo pages, photographer credits, and source image URLs are recorded in `credits.json`. The picker and selected cover link back to the photographers' photo pages.

The images are bundled locally at 1200 × 650. Selecting a preset makes no network requests and sends no vault information to Unsplash. User uploads are private local copies, separate from these assets.
